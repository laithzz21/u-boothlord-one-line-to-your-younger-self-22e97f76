One line in English I would send back to my younger self — personal, specific, warm and a little wry.

## Entry

> Keep grinding in Zarqa, kid — the late nights you're trading for a console today are the same patience that buys you a whole life later.

## Run

```sh
python3 main.py
```

This validates the entry (single line, at most 200 characters, exactly one sentence), writes it to `entry-output.txt`, and verifies the file by reading it back.
